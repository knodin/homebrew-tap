# Security

Do not report a suspected vulnerability in a public issue.

Use GitHub's private vulnerability-reporting flow for this repository when the
problem concerns the Homebrew formula or its release-verification automation.
For a knodin runtime issue, use the private security contact published by
the package owner rather than disclosing exploit details here.

The tap accepts only HTTPS npm tarballs, verifies their SHA-256, and installs
with dependency lifecycle scripts disabled.
